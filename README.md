# QuestionHub

Kullanıcıların gönderi oluşturabildiği, yorum yapabildiği ve içerikle etkileşim kurabildiği bir full-stack web uygulamasıdır.

## Tech Stack

- **Frontend:** React
- **Backend:** Java, Spring Boot
- **Database:** MySQL

## Project Structure

```text
/backend   # Spring Boot REST API
/frontend  # React application
```
